- 연장 시각: 2026-11-19 03:00 (KST)
- 결과: **연장 성공** (Instagram `refresh_access_token`, HTTP 200)
- 새 만료일: **2027-01-18 03:00 (KST)** (expires_in 5,184,000초 = 60일)
- 토큰 문자열: **변경됨** (sha256 앞 8자리 비교: 기존 ≠ 새 값)
- 새 토큰 값은 어디에도 저장하지 않았다(파일·커밋·화면 모두 없음).

## 지금 상태

- 환경 변수 `INSTAGRAM_ACCESS_TOKEN` 은 **기존 토큰 그대로**다. 연장 직후 `/me` 호출 HTTP 200 → 아직 쓸 수 있다.
- 기존 토큰의 원래 만료일은 기록이 없어 **미확인**이다. 11/22 만료 전 확인 알림이 예약돼 있다.
- 새 만료일(2027-01-18)은 새 토큰 문자열에 해당한다. 환경 변수는 기존 값이라 이 만료일이 적용되지 않는다.

## 대표님이 하실 일

1. Meta 개발자 대시보드에서 인스타 토큰을 새로 생성한다.
2. 클라우드 환경의 `INSTAGRAM_ACCESS_TOKEN` 값을 새 토큰으로 바꾼다.
3. 다음 날 08:50 숫자 파일에 오류가 없으면 끝.
