# THING THAT HIT 자동 영상 편집기

영상을 넣으면 아래 작업을 자동으로 해서 **캡컷(CapCut) 초안**으로 만들어 줍니다.
캡컷에서 열어 마지막 손질만 하고 내보내면 됩니다. ([pyCapCut](https://github.com/GuanYixuan/pyCapCut) 사용)

| 작업 | 하는 일 |
|---|---|
| 무음 컷 | 말이 끊긴 구간(기본 0.6초 이상)을 잘라요. 말 앞뒤로 0.15초씩 여유를 남겨요 |
| 버벅임 컷 | "음, 어" 같은 추임새, "이거 이거"처럼 반복한 말, "그, 그러니까"처럼 더듬은 말을 잘라요 |
| 자동 자막 | Whisper로 받아 적고, 한 줄 16자 안쪽으로 나눠서 화면 아래에 넣어요 (흰 글씨 + 검은 테두리) |
| ASMR 모드 | 말이 전체의 15% 미만이면 자동으로 켜져요. 환경음은 그대로 두고, 작은 소리를 키워 잘 들리게 해요. 완전한 무음(1.5초 이상)만 잘라요 |
| 소리 보정 | 말하는 영상: 잡음 줄이기 + 목소리 또렷하게. 둘 다 SNS 기준 음량에 맞춰요 |
| 효과음 | 시작할 때 반짝, 화면이 크게 바뀔 때 휙, "완성/짜잔"엔 띵, "선물/예쁘다"엔 반짝 같은 소리를 넣어요 |

## 1. 처음 한 번만: 설치

PC(윈도우 권장)에서 합니다. 캡컷 초안은 **PC용 캡컷**에서 열려요.

1. [Python](https://www.python.org/downloads/) 설치 (설치할 때 "Add Python to PATH" 체크)
2. 이 폴더(`video_editor`)에서 명령 프롬프트를 열고:

```bash
pip install -r requirements.txt
```

처음 실행할 때 음성 인식 모델(약 500MB)을 자동으로 받아요. 인터넷이 연결돼 있어야 해요.

## 2. 사용하기

**가장 쉬운 방법:** 영상 파일을 `자동편집.bat` 아이콘 위로 끌어다 놓기. (여러 개 한 번에 가능)

**명령어로:**

```bash
python run.py 영상.mp4                   # 기본 (말/ASMR 자동 판단)
python run.py 영상.mp4 --preview         # 캡컷 없이 바로 볼 수 있는 mp4도 만들기
python run.py 영상1.mp4 영상2.mov        # 여러 개 한 번에
python run.py asmr.mp4 --mode asmr --no-subtitles
python run.py 영상.mp4 --min-silence 1.0  # 컷이 너무 빡빡하면 늘리기
python run.py 영상.mp4 --model medium     # 자막이 자주 틀리면 더 큰 모델 (느려짐)
```

끝나면 PC 캡컷을 열어 `자동편집_영상이름` 초안을 확인하세요. (목록에 안 보이면 캡컷을 껐다 켜기)
캡컷 초안 폴더를 못 찾으면 `output/capcut_drafts/`에 만들어지니, 그 폴더를 캡컷 초안 폴더로 옮기거나
`--draft-dir "캡컷 초안 폴더 경로"`로 직접 지정하세요. (캡컷 → 설정 → 초안 위치에서 확인)

### 결과물 (`output/영상이름/`)

- `subtitles.srt` — 자막 파일 (다른 앱에서도 사용 가능)
- `audio_enhanced.wav` — 다듬은 소리
- `report.json` — 어디를 왜 잘랐는지, 효과음을 어디에 넣었는지 기록
- `words.json` — 음성 인식 결과 (다시 돌릴 때 재사용해서 빨라요. 새로 인식하려면 `--retranscribe`)
- `preview.mp4` — `--preview`를 붙였을 때만

### 캡컷 초안 트랙 구성

- `main` 영상: 남길 구간만 이어 붙임 (원본 소리는 꺼 둠)
- `voice` 오디오: 다듬은 소리
- `sfx1`, `sfx2` 오디오: 효과음
- `subtitle` 텍스트: 자막 (캡컷에서 한 번에 글꼴/색 바꾸기 가능)

## 3. 효과음 바꾸기

기본 효과음은 프로그램이 간단히 만든 소리예요. 더 좋은 소리를 쓰려면 `sfx/` 안의 폴더에
mp3나 wav 파일을 넣으면 그걸 씁니다. (여러 개면 무작위로 골라요)

| 폴더 | 들어가는 곳 |
|---|---|
| `sfx/whoosh` | 화면이 크게 바뀔 때 |
| `sfx/sparkle` | 영상 시작, "선물/예쁘/반짝/귀여" |
| `sfx/ding` | "완성/짜잔/다 됐다" |
| `sfx/pop` | "와/대박/헐/우와" |
| `sfx/tap` | "딸깍/톡/붙이/끼우/달아" |

상업적으로 써도 되는 무료 효과음인지 꼭 확인하고 넣으세요.
ASMR 모드에서는 소리가 콘텐츠라서 효과음을 적고 작게(35%) 넣고, 말 키워드 효과음은 넣지 않아요.

## 알아두기 (한계)

- **버벅임 컷은 Whisper가 받아 적은 단어 기준**이에요. Whisper가 추임새를 알아서 지우고 받아 적으면 그 부분은 못 잘라요. 결과를 캡컷에서 한 번 훑어보세요.
- 조용한 영상에서 Whisper가 "시청해 주셔서 감사합니다" 같은 없는 말을 지어내는 경우가 있어서, 자주 나오는 문장은 걸러내고 있어요.
- 효과음은 **화면 전환 감지 + 말 키워드** 기준이에요. 화면 속 물체(예: 레진 붓는 장면)를 알아보고 넣는 건 아니에요.
- 캡컷 버전에 따라 초안이 안 열릴 수 있어요. 그땐 `--preview`로 만든 mp4를 캡컷에 불러와 쓰세요.
