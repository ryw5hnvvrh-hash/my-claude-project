# THING THAT HIT 자동 영상 편집기

영상을 넣으면 아래 작업을 자동으로 해서 **캡컷(CapCut) 초안**으로 만들어 줍니다.
캡컷에서 열어 마지막 손질만 하고 내보내면 됩니다. ([pyCapCut](https://github.com/GuanYixuan/pyCapCut) 사용)

| 작업 | 하는 일 |
|---|---|
| 무음 컷 | 말이 끊긴 구간(기본 0.6초 이상)을 잘라요. 말 앞뒤로 0.15초씩 여유를 남겨요 |
| 버벅임 컷 | "음, 어" 같은 추임새, "이거 이거"처럼 반복한 말, "그, 그러니까"처럼 더듬은 말을 잘라요 |
| 자동 자막 | Whisper로 받아 적고, 한 줄 16자 안쪽으로 나눠서 화면 아래에 넣어요 (흰 글씨 + 검은 테두리) |
| ASMR 모드 | 말이 전체의 15% 미만이면 자동으로 켜져요. 환경음은 그대로 두고, 작은 소리를 키워 잘 들리게 해요. 완전한 무음(1.5초 이상)만 잘라요 |
| 소리 보정 | 말하는 영상: 잡음 줄이기 + 목소리 또렷하게. 둘 다 SNS 기준 음량에 맞춰요 |
| 효과음 | 시작할 때 반짝, 화면이 크게 바뀔 때 휙, "완성/짜잔"엔 띵, "선물/예쁘다"엔 반짝 같은 소리를 넣어요 |

## 0. 아이패드만으로 쓰기 (PC 없이)

편집기를 **Hugging Face 무료 서버**에 올려 두고, 아이패드 사파리에서 주소로 접속해 써요.
결과는 자막·효과음이 입혀진 **완성 mp4**예요. 아이패드 캡컷에서 불러와 마무리하면 돼요.
(pyCapCut의 캡컷 초안은 PC 캡컷 전용이라, 이 방식에서는 만들지 않아요.)

### 처음 한 번만 설정 (아이패드 사파리로 전부 가능, 약 15분)

1. **Hugging Face 가입**: https://huggingface.co/join
2. **서버(Space) 만들기**: https://huggingface.co/new-space
   - Space name: `autoedit` / SDK: **Gradio** / Hardware: **CPU basic (Free)** / **Public** → Create Space
3. **편집기 비밀번호 정하기**: 만든 Space → Settings → *Variables and secrets* → **New secret**
   - Name: `APP_PASSWORD` / Value: 원하는 비밀번호
4. **업로드용 열쇠(토큰) 만들기**: https://huggingface.co/settings/tokens → Create new token
   - Token type: **Write** → 만든 토큰을 복사 (다른 곳에 붙여넣거나 공유하지 마세요)
5. **GitHub에 열쇠 넣기**: GitHub 저장소 → Settings → *Secrets and variables* → *Actions*
   - Secrets 탭 → New repository secret → Name `HF_TOKEN`, 값은 4번 토큰
   - Variables 탭 → New repository variable → Name `HF_SPACE`, 값은 `내HF아이디/autoedit`
6. 이 폴더가 바뀌어 GitHub에 올라가면 자동으로 서버에 올라가요 (GitHub → Actions에서 진행 확인).
   서버 준비에 5~10분 걸려요.

### 매일 쓰기

1. 사파리에서 `https://huggingface.co/spaces/내HF아이디/autoedit` 열기
   (공유 → **홈 화면에 추가**하면 앱처럼 쓸 수 있어요)
2. 아이디는 아무거나, 비밀번호는 3번에서 정한 것
3. 영상 올리기 → **자동 편집 시작** → 끝나면 `…_편집완성.mp4` 받기
4. '파일' 앱에서 길게 눌러 공유 → **비디오 저장** → 아이패드 캡컷에서 불러오기

### 알아두기

- 무료 서버라 느려요. 1분 영상 기준 몇 분 정도 걸릴 거예요(예상). 4K보다 1080p로 찍은 영상이 훨씬 빨라요.
- 48시간 동안 안 쓰면 서버가 잠들어요. 다시 열면 깨어나는 데 1~3분 걸려요.
- 올린 영상과 결과물은 하루 뒤(또는 서버 재시작 때) 자동으로 지워져요. 완성 영상은 바로 받아 두세요.
- 코드는 공개(Public)지만, 편집기 사용은 비밀번호가 있어야 해요. 올린 영상은 다른 사람에게 보이지 않아요.
- **자막을 영상에 입히기**를 끄면 자막 없는 영상이 나와요. 캡컷 자동 자막을 쓰고 싶을 때 쓰세요.

## 1. 처음 한 번만: 설치

PC(윈도우 권장)에서 합니다. 캡컷 초안은 **PC용 캡컷**에서 열려요.

1. [Python](https://www.python.org/downloads/) 설치 (설치할 때 "Add Python to PATH" 체크)
2. 이 폴더(`video_editor`)에서 명령 프롬프트를 열고:

```bash
pip install -r requirements.txt
```

처음 실행할 때 음성 인식 모델(약 500MB)을 자동으로 받아요. 인터넷이 연결돼 있어야 해요.

## 2. 사용하기

### 아이패드로 쓰기 (추천)

편집은 PC가 하고, 아이패드는 사파리로 접속해서 영상을 올리고 받기만 해요.

1. PC에서 `웹편집기.bat`을 더블클릭해요. 검은 창에 이런 주소가 나와요:
   ```
   아이패드 사파리 주소창에 입력하세요:
       http://192.168.0.12:7860
   ```
   처음 켤 때 "Windows 보안 경고" 창이 뜨면 **[허용]**을 눌러 주세요.
2. 아이패드 **사파리**에 그 주소를 입력해요. (자주 쓰면 공유 → **홈 화면에 추가**하면 앱처럼 쓸 수 있어요)
3. **편집할 영상**을 눌러 사진 보관함에서 영상을 고르고 → **자동 편집 시작**.
4. 끝나면 **내려받기**에서 `…_편집완성.mp4`를 눌러요. '파일' 앱 → 다운로드에 저장돼요.
   파일을 길게 눌러 공유 → **비디오 저장**을 누르면 사진 앱으로 옮겨져요.
5. 아이패드 캡컷에서 그 영상을 불러와 마무리해요.

완성 영상에는 자막·효과음·소리 보정이 모두 들어가 있어요. 아이폰·아이패드 기본 촬영(HDR) 영상도
색이 바래지 않게 일반 색으로 바꿔서 만들어요.

**안 될 때**
- 주소가 안 열리면: 아이패드와 PC가 **같은 와이파이**인지 확인하세요. PC 와이파이가 '공용 네트워크'로
  설정돼 있으면 막힐 수 있어요 → 윈도우 설정 → 네트워크 → 와이파이 속성에서 **개인 네트워크**로 바꾸세요.
- 편집하는 동안 PC의 검은 창을 닫거나 PC를 절전 모드로 두면 멈춰요.
- 집 와이파이에서만 쓰세요. 같은 와이파이에 있는 사람은 누구나 이 주소로 접속할 수 있어요.
- PC에서만 쓰려면 `python web.py --local`.

### 파일을 끌어다 놓기 / 명령어로 쓰기

**가장 쉬운 방법:** 영상 파일을 `자동편집.bat` 아이콘 위로 끌어다 놓기. (여러 개 한 번에 가능)

**명령어로:**

```bash
python run.py 영상.mp4                   # 기본 (말/ASMR 자동 판단)
python run.py 영상.mp4 --preview         # 캡컷 없이 바로 볼 수 있는 mp4도 만들기
python run.py 영상1.mp4 영상2.mov        # 여러 개 한 번에
python run.py asmr.mp4 --mode asmr --no-subtitles
python run.py 영상.mp4 --min-silence 1.0  # 컷이 너무 빡빡하면 늘리기
python run.py 영상.mp4 --model medium     # 자막이 자주 틀리면 더 큰 모델 (느려짐)
```

끝나면 PC 캡컷을 열어 `자동편집_영상이름` 초안을 확인하세요. (목록에 안 보이면 캡컷을 껐다 켜기)
캡컷 초안 폴더를 못 찾으면 `output/capcut_drafts/`에 만들어지니, 그 폴더를 캡컷 초안 폴더로 옮기거나
`--draft-dir "캡컷 초안 폴더 경로"`로 직접 지정하세요. (캡컷 → 설정 → 초안 위치에서 확인)

### 결과물 (`output/영상이름/`)

- `subtitles.srt` — 자막 파일 (다른 앱에서도 사용 가능)
- `audio_enhanced.wav` — 다듬은 소리
- `report.json` — 어디를 왜 잘랐는지, 효과음을 어디에 넣었는지 기록
- `words.json` — 음성 인식 결과 (다시 돌릴 때 재사용해서 빨라요. 새로 인식하려면 `--retranscribe`)
- `preview.mp4` — `--preview`를 붙였을 때만

### 캡컷 초안 트랙 구성

- `main` 영상: 남길 구간만 이어 붙임 (원본 소리는 꺼 둠)
- `voice` 오디오: 다듬은 소리
- `sfx1`, `sfx2` 오디오: 효과음
- `subtitle` 텍스트: 자막 (캡컷에서 한 번에 글꼴/색 바꾸기 가능)

## 3. 효과음 바꾸기

기본 효과음은 프로그램이 간단히 만든 소리예요. 더 좋은 소리를 쓰려면 `sfx/` 안의 폴더에
mp3나 wav 파일을 넣으면 그걸 씁니다. (여러 개면 무작위로 골라요)

| 폴더 | 들어가는 곳 |
|---|---|
| `sfx/whoosh` | 화면이 크게 바뀔 때 |
| `sfx/sparkle` | 영상 시작, "선물/예쁘/반짝/귀여" |
| `sfx/ding` | "완성/짜잔/다 됐다" |
| `sfx/pop` | "와/대박/헐/우와" |
| `sfx/tap` | "딸깍/톡/붙이/끼우/달아" |

상업적으로 써도 되는 무료 효과음인지 꼭 확인하고 넣으세요.
ASMR 모드에서는 소리가 콘텐츠라서 효과음을 적고 작게(35%) 넣고, 말 키워드 효과음은 넣지 않아요.

## 알아두기 (한계)

- **버벅임 컷은 Whisper가 받아 적은 단어 기준**이에요. Whisper가 추임새를 알아서 지우고 받아 적으면 그 부분은 못 잘라요. 결과를 캡컷에서 한 번 훑어보세요.
- 조용한 영상에서 Whisper가 "시청해 주셔서 감사합니다" 같은 없는 말을 지어내는 경우가 있어서, 자주 나오는 문장은 걸러내고 있어요.
- 효과음은 **화면 전환 감지 + 말 키워드** 기준이에요. 화면 속 물체(예: 레진 붓는 장면)를 알아보고 넣는 건 아니에요.
- 캡컷 버전에 따라 초안이 안 열릴 수 있어요. 그땐 `--preview`로 만든 mp4를 캡컷에 불러와 쓰세요.
