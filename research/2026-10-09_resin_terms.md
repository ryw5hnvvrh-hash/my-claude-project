# 레진 용어 조사 — 2026-10-09 (금) · 시장조사팀 이승희

대표 지시(10/9): "오늘 정보성 캐러셀 올리자, 레진 용어 조사해줘"
기준: 웹 검색(나무위키·공예 교육기관·재료 쇼핑몰·커뮤니티). 정의가 업체마다 조금씩 다름 → 캐러셀엔 쉬운 말로만. 경화 시간·배합비는 **제품마다 다름**(제품 설명서 기준).

| 용어 | 쉬운 뜻 | 출처에 적힌 사실 | 우리 작업과 연결 |
|---|---|---|---|
| 2액형 레진 (에폭시) | 두 액(주제+경화제)을 섞어 굳히는 레진 | 주제·경화제로 나뉜 레진, '자연경화 레진'이라고도 함 · 비율대로 섞고 3~24시간 경화 | 아이원츄 본체 2액형 8.5g (원가표) |
| UV레진 | 자외선(램프)을 쬐면 굳는 1액형 레진 | 섞을 필요 없는 1액형 · 램프에 따라 3~10분 · 램프와 맞지 않으면 잘 안 굳음 · 불투명 몰드는 빛이 안 통해 못 씀 | 아이원츄 UV레진 6g |
| 경화 | 액체 레진이 단단하게 굳는 것 | 2액형은 시간이 오래, UV는 빛을 쬐면 빠르게 | 9/30 '자연경화 때문에 릴스 못 올림' — 실제 기다림 |
| 기포 | 섞거나 부을 때 생기는 공기 방울 | 천천히 1~2분 섞기 · 열(힛툴·토치)로 표면 기포 제거 · UV는 바르고 잠시 두면 줄어듦 | 투명 하트라 기포가 보이면 실패 → '실패 4개 중 1개'(원가표) |
| 탈형 (이형) | 굳은 레진을 몰드에서 꺼내는 것 | 실리콘 몰드는 유연해서 꺼내기 쉬움 · 플라스틱 몰드는 오일·바셀린을 먼저 바름 | 하트 쉐이커 몰드(2,900원, 30번 사용) |
| 몰드 (실리콘 몰드) | 모양을 찍어내는 틀 | 쉐이커 몰드 = 속이 빈 틀 · 투명하고 얇은 실리콘이 UV 작업에 좋음 | 1칸 하트 몰드 |
| 쉐이커 | 속에 오일·파츠를 넣어 흔들면 움직이는 레진 소품 | 빈 틀에 레진을 굳힌 뒤 안에 오일·워터·파츠를 넣어 완성 | 아이원츄 = 하트 쉐이커 그립톡 (I WANT YOU 글자가 떠다님) |
| 쉐이커 오일 | 쉐이커 안을 채우는 투명 액체 | 오일이나 물을 넣고 파츠를 띄움 | 아이원츄 오일 4g |
| 점도 (저점도·고점도) | 레진이 묽은지 되직한지 | 묽을수록 기포가 잘 빠짐 | — |
| 황변 | 시간이 지나며 누렇게 변하는 것 | 질 좋은 레진일수록 적음 · 2액형은 황변 우려 · 2액형에 UV램프를 쬐면 황변만 생길 수 있음 | ⚠️ 우리 제품 '황변 없음'이라고 쓰지 않기(확인 안 됨) |

# 전문 풀이 (대표 요청 10/9 "조금 더 전문적이게 뜻해석해줘")

| 용어 | 전문 풀이 | 근거 |
|---|---|---|
| 2액형 레진 (에폭시 수지) | 주제(A액 에폭시 수지)와 경화제(B액, 주로 아민계)를 정해진 비율로 섞으면 화학 반응으로 그물 모양 구조(가교 구조)가 생겨 굳는 열경화성 수지. 경화제는 반응하면서 수지 구조의 일부가 됨 → 비율이 틀리면 덜 굳거나 물러짐 | 나무위키 에폭시 · 씽크존 · 스윗츠데코 |
| 가사시간 | 섞은 뒤 부을 수 있을 만큼 묽은 상태가 유지되는 작업 가능 시간. 경화제 종류·양·온도에 따라 달라짐 | 씽크존 · 웨스트시스템 |
| 발열 반응 | 경화 반응은 열을 냄. 한 번에 많이·두껍게 부으면 열이 쌓여 빨리 굳고, 기포가 빠지기 전에 굳어 투명도가 떨어질 수 있음 | 웨스트시스템 · 스윗츠데코 · 학술 자료 |
| UV레진 (광경화 수지) | 안에 든 광개시제가 자외선을 받으면 반응을 시작시키는 성분(라디칼)을 만들고, 이것이 수지 분자를 연결(중합)해 굳힘. 그래서 빛이 닿는 곳만 굳음 | 지차이케미컬 |
| 미경화 | 두껍게 바르거나 빛이 부족해 반응하지 않은 성분이 남은 상태. 표면이 끈적이고, 나중에 성분이 배어 나올 수 있음 | UV경화 불량 자료 · 지차이케미컬 |
| 산소 저해 | 공기 중 산소가 반응 성분을 소모해 표면만 끈적하게 남는 현상 | ⚠️ 검색 출처 없음 — 일반 지식, 캐러셀엔 넣지 않기 |
| 기포 | 섞는 과정에서 들어간 공기. 점도가 낮고 천천히 굳는 레진일수록 기포가 위로 올라와 빠질 시간이 있음 · 표면은 열로 점도를 낮춰 제거 | 스윗츠데코 · 청강메이커스랩 |
| 탈형 | 경화가 끝난 성형물을 몰드에서 분리하는 공정. 실리콘 몰드는 탄성이 있어 이형제 없이도 잘 빠지고, 딱딱한 몰드는 오일·바셀린 같은 이형제를 먼저 바름 | 청강메이커스랩 · 나무위키 |
| 황변 | 자외선·열에 의해 수지 안의 일부 구조(발색단)가 산화·분해되며 누렇게 변하는 현상. 아민 성분, 남은 광개시제, 고온 경화·직사광선 보관이 원인으로 꼽힘 → UV 차단 마감, 그늘 보관으로 늦출 수 있음 | 지차이케미컬 · 아디터나우 · 카페 게시글 |
