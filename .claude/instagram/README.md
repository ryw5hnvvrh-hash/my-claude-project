# .claude/instagram

`voice.md` (voice profile) and `swipe.md` (outlier research from /ig-viral) are every ig-* skill reads from `~/.claude/instagram/voice.md`.
Cloud sessions start with an empty home directory, so restore it at the start of a session:

    mkdir -p ~/.claude/instagram && cp .claude/instagram/voice.md .claude/instagram/swipe.md ~/.claude/instagram/

Edit this copy, then copy it again. `voice.template.md` is the blank original from the skill pack.
