# 정산 입력 자료

대표가 한 주 동안의 기록을 이 폴더에 넣는다. 정산팀은 매주 일요일 오후 5시(한국시간)에 이 자료만 보고 정산한다.
두 판매 사이트는 로그인이 필요해서 AI가 직접 접속하지 않는다.

## 판매금액 (2곳)

| 플랫폼 | 사이트 | 넣을 폴더 |
|---|---|---|
| 스마트스토어 | https://sell.smartstore.naver.com/#/home/dashboard | `smartstore/` |
| 아이디어스 | https://artist.idus.com | `idus/` |

- 각 사이트에서 지난 한 주(월~일) 주문·정산 내역을 내려받아(엑셀/CSV) 넣는다. 내려받기가 어려우면 화면 캡처도 된다.
- 파일 이름 예: `2026-10-04_week.xlsx`
- 필요한 항목: 주문일 / 제품 / 주문 금액 / 수수료 / 실제 입금(정산) 금액 / 입금 예정일
- 인스타 샵 주문은 스마트스토어·아이디어스에서 결제되므로 따로 넣지 않는다.

## 그 외 (이 폴더에 직접)

파일 이름 예: `2026-10-04_week.md`
- 광고비: 집행 날짜 / 플랫폼 / 금액 / 대상 콘텐츠
- 재료비: 구매일 / 품목 / 금액 / 구매처 / 사용 제품
